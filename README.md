# Life Tracker v3.1 • Ultimate Premium Restored

Mobile-first personal life management PWA. This release combines the complete v2.0 tracker modules with a refreshed premium responsive interface and persistent light/dark theme.

## Included modules
- Dashboard and daily checklist
- Five daily prayer checklist
- Daily habits and custom tasks
- Honours, English and other study sessions
- Health log: sleep, water, exercise, mood and notes
- Income, expenses, monthly budget and finance CSV
- 6-day day / 6-day night shift cycle planner
- Goals with progress controls
- Career and skill practice tracker
- Monthly and yearly reports
- JSON backup and restore
- Optional browser notification permission
- Light / dark appearance

## Privacy
Data is stored locally in this browser using localStorage. No account, analytics, camera, gallery, contacts, microphone or location access is used. Export JSON backups regularly. Clearing browser site data can erase app data.

## Install / update
Upload the contents of this folder to the root of your GitHub Pages repository, replacing the old app files. Open the site and refresh. If an old version remains, close the installed PWA/browser tab, clear only this site's cached files if needed, then reopen. Keep a JSON backup before replacing an existing app.
